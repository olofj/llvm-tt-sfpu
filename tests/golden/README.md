# Golden Reference Files

This directory holds checked-in reference outputs for GCC and LLVM compiled kernels.
Any change to golden files is visible in git diff, providing an audit trail.

## File naming convention

```
{arch}-{kernel}-{compiler}.json
```

Example: `wh-softmax-gcc.json`, `wh-softmax-llvm.json`

## JSON format

```json
{
  "kernel": "softmax",
  "arch": "wh",
  "compiler": "gcc",
  "compiler_version": "riscv32-unknown-elf-gcc 13.1.0 (TT fork)",
  "timestamp": "2026-03-26T12:00:00Z",
  "instructions": [
    {"asm": "sfpload l0, 0, 0, 0", "word": "0x70000003", "cycle": 1},
    {"asm": "sfpmad l0, l0, l8, l9, 0", "word": "0x84089003", "cycle": 2}
  ],
  "total_insns": 6,
  "total_nops": 2,
  "input_values": [0.0, 0.5, 1.0, 2.0, -1.0],
  "expected_outputs": {
    "L0": ["0x00000000", "0x3F317218", "0x3F800000", "0x40490FDB", "0xBF317218"]
  }
}
```

## Usage

Golden files are generated by:
```bash
python3 tests/vectors/run_ttsim_compare.py --arch=wh --generate-golden
```

And validated by:
```bash
python3 tests/vectors/run_ttsim_compare.py --arch=wh --check-golden
```
